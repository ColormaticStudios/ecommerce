# Ecommerce AI Disclosure

The scope of this project is very large, and is unfeasible for a single developer to tackle before AI generated code became good enough. However, the core architecture, feature design, and code practices are designed by a human developer. The goal is to get a working product as fast as possible and then spend a long time refining it. However, to get the best result, the foundation of the project needs to be tightly controlled from the start.

Almost 100% (not quite all) of the code is generated by AI, but is closely reviewed and scrutinized. The images for the test products in the development environment were created by the developer; not AI generated. The product images in Storybook were sourced from Unsplash.

This project is mostly AI generated, but with lots of human steering, especially for core decisions.
